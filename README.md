# Analysis of Nighttime Light Intensity: Kolkata (2015 vs 2020)

## Project Overview
This project uses **Google Earth Engine (GEE)** to analyze changes in nighttime radiance in Kolkata, India. By comparing data from May 2015 and May 2020, the analysis highlights urban sprawl and the unique atmospheric/economic signature during the COVID-19 lockdown.

## Tech Stack
- **Platform:** Google Earth Engine (JavaScript API)
- **Dataset:** VIIRS Stray Light Corrected Nighttime Day/Night Band (DNB)
- **GIS Software:** QGIS (for final cartographic styling)

## Key Findings
- **2015 Baseline:** Shows the established urban footprint.
- **2020 Snapshot:** Captured during the lockdown, providing a rare look at radiance intensity shifts.
- **Tools Used:** `ImageCollection` filtering, `median()` reduction, and `clip()` operations.
